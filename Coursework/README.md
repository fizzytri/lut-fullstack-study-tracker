# Coursework

The exercise projects I did while going through the tutorial series in the Moodle course
*Software Development Skills: Full-Stack*. One folder per module.

| Module | Folder | Topic |
| --- | --- | --- |
| 1 | `01-nodejs` | Modules, core APIs, events, plain HTTP server |
| 2 | `02-mongodb` | Mongoose schemas, CRUD, query operators, grouping |
| 3 | `03-expressjs` | Routers, middleware, REST, static files |
| 4 | `04-react` | Components, props, state, hooks, forms |
| 5 | `05-mern` | All of it together with login and a protected resource |

Each folder installs on its own:

```bash
cd Coursework/01-nodejs
npm install
npm start
```

Modules 2 and 5 need MongoDB running.

The  project I built after these is in [`../project`](../project).
