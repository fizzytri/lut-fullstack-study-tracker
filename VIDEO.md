# Project demo video

A screen recording of the Study Tracker running locally, walking through registration,
adding a course, logging study sessions, creating a goal and the dashboard.

**Video link:** https://lut-my.sharepoint.com/:v:/g/personal/diako_jalal_student_lut_fi/IQBmHNQAapYcT6s8zV4o6w-sATgZ3xZRarmtpnbYFK0OWBU?e=Un79hw 

## What the recording shows

1. `npm run seed` and both servers starting
2. Registering a new account and being redirected to the dashboard
3. Adding a course on the Courses page, editing it, and the validation error on a duplicate code
4. Logging a study session and seeing the dashboard
5. Creating a goal and watching its progress bar 
6. Changing the weekly target on the Profile page 
7. Logging out and being redirected to the login page by the protected route
